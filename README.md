# The Table — Online Food Ordering System

A professional, responsive front-end demo built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Features
- Editorial restaurant-style layout and food photography
- Menu category filtering
- Shopping cart with quantities and subtotal
- Delivery details form and demo order confirmation
- Responsive desktop and mobile layout
- Browser localStorage for demo cart/order state

## Deploy to GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root.
3. Commit changes to `main`.
4. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`.
5. Wait for the deployment to complete in **Actions**.

## Limitations
This is a front-end demonstration. GitHub Pages does not run PHP or MySQL. Checkout saves the demo order in the current browser only; it does not process payment or transmit orders. A production system requires a backend, database, authentication, validation, and secure payment integration hosted separately. Food photography loads from Unsplash and therefore needs an internet connection.
